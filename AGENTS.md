# Repository guidance

This repository contains specialist prompt profiles and integration tooling.

## Using Agency Agents

When the user asks to use Agency Agents for a task, read `.agents/skills/agency-agents/SKILL.md`, select the relevant profile, and read that profile in full before working. Match the user's language. See `KULLANIM-TR.md` for Turkish usage examples.

Use only the profiles relevant to the task. Treat profile personas as task guidance, not evidence of real experience, persistent memory, or permission to take unrelated actions.

## Maintaining this repository

For edits to specialist profiles or integration tooling, read `CONTRIBUTING.md` and the relevant existing files. Follow `SECURITY.md` for security reporting. Preserve the upstream license and attribution. Run checks relevant to the files changed, and report what was actually verified.
